# Gentrit Rashiti, portfolio

Single-page portfolio. Vite 8, React 19, TypeScript, Tailwind 4, `motion`, Phosphor icons.

```sh
source ~/.nvm/nvm.sh
npm install
npm run dev       # http://localhost:5173
npm run build     # typecheck and production build into dist/
npm run preview   # serve dist/
```

Visual system and the world contract: `DESIGN.md`. World builders: `src/worlds/README.md`.
