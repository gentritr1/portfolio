# Motion lab source checks

Source review date: 4 October 2026. Scope: all 17 studies at [/drafts/lab](/drafts/lab), their small reused helpers, and the lab lifecycle. The source sections describe code inspection and the checks actually run by the builders. Root's later in-app-browser observations are recorded separately below. Neither section is an audio, print-output or physical-device acceptance report.

## Shared lifecycle and measurement

The [lab shell](../../src/drafts/lab/Draft.tsx) lazy-loads each tile from its own module. IntersectionObserver activates visible tiles. Offscreen tiles, the global Pause state and a hidden document unmount the tile, so effect cleanup releases its working resources. A tile returning to view starts a fresh local state; this is not a promise to preserve every selection across suspension. The shell removes its observers/listeners and aborts its size-report request on unmount. Reduced motion combines the device preference and the lab control.

The tile interface is `active` and `reduced`. Interactive controls remain native buttons, selects, checkboxes, sliders or a keyboard-focusable scroll region. Each study has a scoped palette and feedback states. Source properties alone do not prove that controls fit the fixed 330 px desktop / 340 px phone stage; the observed fit and expanded-case checks are recorded below.

The final production measurement belongs to [draft-budgets.json](draft-budgets.json). `labMoves` measures each tile's recursive production JS/CSS graph after the initial graph, picker and lab shell have loaded. `labUnion` deduplicates shared modules across the studies. These are measured costs, not the consult's planning allowances. Self-hosted fonts, public images, the MSDF atlas and other public assets are separate transfers. There is no external cursor server or live visitor connection.

## Executed source and numerical checks

These checks were reported or run in the builder sessions. They are not browser tests.

- **Compilation, lint and registration:** each owned tile batch passed full TypeScript and targeted Oxlint. After the bounded stage-layout repair, the integration builder reported full TypeScript and lint over the whole lab passing, plus 17 unique registered IDs matching the 17 TSX default exports, style files and measured-size entries. The root-authorized combined manifest build, final-route/lab lint and measurement passed at 03:15:33 UTC on 4 October 2026; the 26 route graphs and 17 tile measurements are in the budget record. This is build evidence, not browser fit or speed evidence.
- **Report generator:** temporary fixtures checked all 17 filename mappings, measured union values, missing-budget labels, all 25 motion references, the explicit LAP diagnostic failure and the LEDGER density exception. The test did not generate the repository's final DRAFTS.md; root runs that after final metadata and measurement.
- **CSS3D matrix arithmetic, builder report:** actual OGL Camera/Transform values were compared with the CSS homogeneous mapping for all four corners, viewport sizes 315 × 263, 600 × 253 and 1200 × 500, and yaw −0.30, 0 and 0.30. All 36 corner cases passed; maximum error was 2.542 × 10⁻¹³ px and the matrices were invertible. This proves the tested arithmetic, not DOM hit testing or displayed alignment.
- **Fluid pipeline, builder report:** a mocked WebGL harness checked seven 128² RGBA16F targets, 20 pressure passes per frame, two advections, the three-input queue cap/six splats, no simultaneous read/write texture use, Clear cancelling its frame, complete texture/framebuffer/program/listener cleanup, and null fallback for missing float support or an incomplete framebuffer. It did not compile shaders on a GPU or measure frame rate.
- **Board bitmap and letter lifecycle, executed in this agent:** both shapes retained exactly 6,912 bitmap cells and produced non-empty FJALË lettering. A mocked frame scheduler settled a 74 px letter drop in 25 simulated 60 Hz frames, with no remaining transform or frame. Disposal during a fall also removed both; reduced motion queued no frame. This tests the finite state/lifecycle, not the visible feel of rebounds.
- **Solar arithmetic, executed in this agent:** 4 October 2026 calculated noon was 10:26:25.018 UTC, with 43.1408587° altitude. The returned direction was a unit vector; reduced output used the calculated noon timestamp, and 12:00 UTC displayed as 14:00 in Europe/Belgrade on that date. These are calculation checks, not an astronomical accuracy certification.
- **MSDF build and coverage:** the LAP build pipeline used actual MSDFgen edge colouring and multi-channel distance generation, then generated the shipped PNG. Source checks confirmed atlas glyphs for BAYYINAH TV, FUTURISMA and FJALË. The separate extrusion pipeline checked face/hole areas and binary index bounds for LAP; that geometry is not loaded by the lab's name-morph tile. Build checks do not prove the shader's rendered appearance.
- **Receipt extraction equivalence, builder report:** actual Receipt rendering through React's static renderer and the actual text function were compared with the original AISLE functions from HEAD for 0, 1 and 3 selections. HTML and text matched exactly. This does not verify browser pagination, print-dialog behavior or a downloaded file.
